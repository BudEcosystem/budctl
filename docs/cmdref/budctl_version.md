## budctl version

Show the budctl version, and what is deployed when a cluster is reachable

```
budctl version [flags]
```

### Options

```
      --client   print only the budctl version, without contacting a cluster
  -h, --help     help for version
```

### Options inherited from parent commands

```

      --kubeconfig string   path to kubeconfig (default: the usual discovery)
      --no-color            disable colour (also NO_COLOR)
```
