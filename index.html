budctl

Is this cluster fit to host Bud? Answer before you install anything.

curl -fsSL https://get.budecosystem.com/install.sh | sh

The script verifies the published SHA-256 before it decompresses or runs anything. It installs to /usr/local/bin, or ~/.local/bin when that is not writable. Set BUDCTL_INSTALL_DIR to choose, BUDCTL_VERSION to pin, or BUDCTL_BASE_URL to install from an internal mirror.

Prefer not to pipe a script into a shell? Take the binary for your platform from Releases, check it against SHA256SUMS, and gunzip it. The tool needs no installer to work.

budctl carries client-go, Helm, SOPS and age as libraries, so no kubectl, helm, sops or age binary has to be present. All it needs is a kubeconfig with a reachable API server.
